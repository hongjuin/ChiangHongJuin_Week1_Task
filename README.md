# ChiangHongJuin_Week1_Task
LED reaction game:
Users can set their time limit using potentiometer. First, five of led will light out three randomly then they are required to extinguish all the light out LED by pressing corresponding button within time limit. If they fail to extinguish all the light out LED three round, all five LED will blink 5 seconds then continue the new round; otherwise they successfully extinguish LED three round, sixth LED will blink 5 seconds while 5 LED remain light off. Whatever win or lose three round, five LED will remain off 1 second before new round start.
